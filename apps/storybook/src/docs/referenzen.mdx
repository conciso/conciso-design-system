# Quellen

Externe Referenzen, die als Grundlage für Entscheidungen in diesem Design System dienten,
sowie die Repo-internen Dokumente, die den Rest des Systems erschließen.

## Externe Referenzen

| Thema | Quelle | Wofür |
|---|---|---|
| Komponentensystem | [Material Design](https://m3.material.io) | Grundlage für Komponentenarchitektur, Elevationssystem, Button-Typen, Card-Varianten und Spacing-Prinzipien |
| Typografie | [Google Fonts](https://fonts.google.com) | Quelle für Libre Baskerville (Display/Headline) und Montserrat (Title/Body/Label), beide frei lizenziert (SIL Open Font License) |
| Icons | [Lucide](https://lucide.dev) | Quelle für alle UI-Icons im Outline-Stil, frei unter ISC-Lizenz, 24×24-Raster mit runden Enden; `lucide-static` für CSS und HTML, `@lucide/angular` für Angular (ADR-0016) |
| Barrierefreiheit | [WCAG 2.2 Quickref](https://www.w3.org/WAI/WCAG22/quickref/) | Offizielle Kriterien-Übersicht des W3C, Referenz für alle WCAG-Verweise in `Grundlagen/Barrierefreiheit` (Kontrast, Tastaturnavigation, ARIA, Touch Targets, Reduzierte Bewegung) |

## Repo-Dokumente

Wer im Storybook landet und den Rest des Repos nicht kennt, findet hier den Einstieg:

| Dokument | Wofür man es aufschlägt |
|---|---|
| `README.md` | Einstieg ins Repo: was das Design System ist und für wen es gedacht ist |
| `CONTRIBUTING.md` | Die Konventionen, nach denen das System gebaut ist: Namensschema, Farbe und Kontrast, Elevation, Dark Mode, Typografie, Spacing, Doku-Struktur |
| `CONTEXT.md` | Das Glossar des Repos: CSS-Schicht, Angular-Lib, Wrapper-Komponente, DS-Glyphen und weitere Begriffe genau so verwenden, wie sie dort definiert sind |
| `docs/GETTING-STARTED.md` | Wie das Design System in ein Projekt eingebunden wird: Einbindereihenfolge der CSS-Dateien, Fonts, Dark Mode, optionales JavaScript, Tokens, Icons, Frameworks |
| `docs/adr/` | Die Architekturentscheidungen des Repos als einzelne ADRs, etwa zur Angular-Lib als CSS-Wrapper (ADR-0001) oder zu Storybook, Docgen-Server und MCP (ADR-0006) |
| `docs/agents/` | Die Agenten-Skills dieses Repos: Issue-Tracker, Triage-Labels, Storybook-Werkzeuge und die Domain-Doku-Struktur |
